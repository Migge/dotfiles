# Emacs Configuration

This directory contains my personal GNU Emacs configuration.

## Guidelines

- Prefer built-in Emacs functionality when practical.
- Keep configuration compatible across my Linux machines.
- Use Emacs Lisp conventions and idioms.
- Explain non-obvious configuration changes.
- Avoid unnecessary dependencies.
- Do not modify downloaded packages or generated Emacs files.
- Keep changes focused and easy to review.
